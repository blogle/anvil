Control plane, not worker runtime

Observe the world. Then decide.

The outer loop is a reconciler supervised by an external Ralph-style loop. It watches durable state and remote systems, refreshes context when useful, and emits typed decisions instead of burying policy in callbacks.

Outer reconciler

Signals are triggers, not truth. A session event, CI callback, timer, or human action wakes reconciliation. The reconciler re-reads state, computes findings, asks Commission policy for one Decision, then records and executes an Operation under ownership.

Context refresh

Repository instructions remain authoritative: AGENTS.md and repository skills own local conventions. Anvil adds operational and reporting protocol, the Campaign / Commission / Assignment / Attempt hierarchy, and the current Finding set. It does not paste the whole history into every turn.

Existing session continuation can receive a smaller delta. Structured agent reports and todos are useful, non-authoritative signals.

Still open: “not converging” needs a policy, not a magic counter. Timeouts, repeated findings, model confidence, and cost may be inputs; exact corrective strategy is an open decision.

Evidence versus claimed progress

Claim

Useful signal

“I updated the parser”; a todo marked complete; a session that says it is ready. These help select what to inspect next.

Evidence

Gate material

A named check result, exact revision, captured output, and timestamp. It can be replayed or inspected and cannot migrate to a different Candidate.

Campaign graph across repositories
One Commission remains one integrable change; a Campaign coordinates independent Commissions and their dependencies. Whether a dependent graph maps to stacked branches, staged PRs, or another integration mechanism is unresolved.


Command safety and observation
Observe broadly
  • OpenCode session and turn metadata
  • Todos and structured agent reports
  • Tool results and watchdog signals
  • Git revision/base and CI results
  • Remote PR and workspace state
Mutate narrowly
  • One mutable writer per workspace
  • Explicit operation owner and id
  • Precondition from fresh observation
  • Safe retry or visible escalation
  • Postcondition observation recorded
The precise command allowlist, sandbox boundary, operation lease, and idempotency key model are implementation questions, not smuggled in by this diagram.
